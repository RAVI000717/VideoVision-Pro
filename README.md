# Video Services Website

A professional website showcasing comprehensive video production and editing services.

## Project Structure
- `index.html` - Main landing page
- `css/` - Stylesheet directory
  - `style.css` - Main stylesheet
- `js/` - JavaScript directory
  - `main.js` - Main JavaScript file
- `images/` - Image assets directory

## Features
- Responsive design
- Modern UI/UX
- Service showcase
- Portfolio section
- Contact form

## Setup
1. Clone the repository
2. Open index.html in a web browser

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
